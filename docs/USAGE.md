# 日常使用

小派是常驻在这台 Windows 笔记本上的个人助手。待机时不把你说的每句话都当命令；进了会话才听、才答。

## 启动

1. 双击 `run.bat`。
2. 窗口出现「状态：待机」，识别一行应是 **SenseVoice（本地）**。
3. 任务栏右侧会出现托盘图标。

若识别仍显示 Whisper 备用：先科学上网，运行 `run.bat --download-models`，再重新双击 `run.bat`。

只打字、不占麦克风：`run.bat --text-only`。

## 怎么开始听

四选一即可，效果相同：

| 方式 | 做法 |
|---|---|
| 唤醒词 | 说 **「你好小派」** 或 **「嗨小派」** |
| 热键 | `Ctrl+Shift+L`（不要用 F8，会开飞行模式） |
| 命令 | 控制台输入 `/listen` 回车 |
| 托盘 | 右键图标 →「开始听」 |

只说「你好」、不带名字，**不会**进会话。也可以连着说：「你好小派，打开记事本」。

改显示名：编辑 `config/identity.yaml` 的 `identity.name`，重启。不要靠口头改名。

## 一轮对话怎么走

```text
待机
  → 唤醒 / 热键 / /listen / 托盘
  → 聆听（你说完，停顿约 1 秒即提交）
  → 思考（可能调用工具）
  → 播报（语音进才出声；打字只出文字）
  → 再听约 10 秒（直接说下一句，不必再唤醒）
       ├ 你开口 → 再答 → 再开 10 秒
       └ 一直没说话 → 回待机
```

约定：

- **语音进 → 语音出；键盘进 → 只出文字。**
- 播报时你可以开口或按热键打断，她会改听你。
- 说 **「退出」** 立刻回待机，程序还在。
- 输入 **`/quit`** 或托盘「退出」才关掉进程。

## 常用说法

| 你说 | 她会 |
|---|---|
| 打开记事本 / 计算器 / 浏览器 | 启动对应应用 |
| 我在看什么 / 当前窗口 | 读前台窗口标题 |
| 剪贴板里是什么 / 我刚复制的 | 读剪贴板文字 |
| 今天有什么安排 / 下午有没有会 | 只读 Outlook 日历和待办 |
| 十分钟后提醒我喝水 / 三点叫我 | 本机到点开口提醒 |
| 电量多少 / 磁盘还剩多少 | 读本机舰况 |
| 忘掉那次行程 / 以后叫我X | 遗忘或纠正长期记忆 |
| 老板是张三 / 主项目是… | 记下人物、项目、偏好 |
| 会议中不要出声 / 晚上十点后只提醒 | 开关说话协议 |
| 今天简报 / 早报 / 我要走了 / 下班了 | 短简报：日程、未完成提醒、异常舰况 |
| 音量调大 / 调小 / 静音 | 调系统音量 |
| 勿扰 / 取消勿扰 | 助手不出声（不是系统专注助手） |
| 锁屏 / 锁定电脑 | 立刻锁工作站 |
| 确认关机 / 确认重启 / 确认睡眠 | 危险操作，必须带「确认」 |
| 帮我后台搜一下… | 先去做，做完再插一句；期间还能说话 |
| 看看屏幕 / `/shot` | 截屏并 OCR |
| 记住我叫… / 我喜欢… | 写入长期记忆 |
| 退出 | 回待机 |

控制台命令：`/listen` 开始听，`/shot` 截屏，`/quit` 退出程序。托盘还可「显示/隐藏控制台」「开机启动」。

托盘圆点颜色：**蓝=待机，绿=聆听中，黄=思考中，白=播报中**。控制台同步打印【待机】【聆听中】等。

日历目前只读 **经典 Outlook**（已登录）。新版 Outlook 网页壳读不到。提醒存在本机数据库，关程序后仍会在下次启动时补报已到期的条目。

开机后若在早上 5–12 点或傍晚 17–23 点，会自动播一段短简报（同一天同一种只播一次）。Outlook 读不到就跳过日程，不会卡住。静音 / 会议中仍只显示不播报；夜间允许简报和后台完成提示，与提醒同类。

关机、重启、睡眠、删除工作区文件：必须你本轮说「确认」。锁屏不必确认。删文件只限工作区里的单个文件。

网页搜索默认走**必应**（这台机器能直连）。`ddgs` 自带的 Yahoo / Startpage / Google 在国内常超时，所以不再当默认。若要走海外源，在 `.env` 设 `WEB_SEARCH_PROXY=`，并把 `WEB_SEARCH_BACKEND=auto`。

## 语音与播报

- 识别：本机 **SenseVoice**（sherpa-onnx）。不经过 DeepSeek。模型在 `models/sensevoice/`。
- 备用：本机 Whisper `base` → 再不行才在线识别。
- 播报：默认 **edge-tts 晓晓**（需能访问微软语音服务）。断网退回系统「慧慧」。
- 改声线：`.env` 里 `TTS_VOICE=`  
  `zh-CN-XiaoxiaoNeural`（晓晓） / `zh-CN-YunxiNeural`（云希） / `zh-CN-YunyangNeural`（云扬）

灵敏度、停顿、再听时长都在 `.env`，改完重启即可。模板见 `.env.template`。常用项：

- `VOICE_SILENCE_END=1.0` 说完停顿多久算一句结束
- `VOICE_FOLLOWUP_SECONDS=10` 播完再听多久
- `VOICE_HOTKEY=CTRL+SHIFT+L`
- `WAKEWORD_ENABLED=true` 关掉后只靠热键 / `/listen` / 托盘

## 记忆

- 每轮对话都会写入会话日志。
- 寒暄不进长期记忆。
- 「记住…」、自我介绍、偏好、纠正她时会写入长期记忆，之后可问「我叫什么」。
- 人格与说话风格在 `config/identity.yaml`，不硬编码在程序里。

## 常见问题

**喊了「你好」没反应**  
要带上名字：「你好小派」。窗口里应出现唤醒成功，而不是一直待机。

**启动显示 Whisper 备用**  
SenseVoice 模型还没下到本机。`run.bat --download-models` 后重启。

**热键没反应**  
确认没有别的软件占用 `Ctrl+Shift+L`。不要用 F8。

**播报把她自己打断了**  
回声误触发。可把 `.env` 里 `VOICE_BARGE_IN_ENERGY` 调大一点，或播报时用热键打断。

**只想打字**  
`run.bat --text-only`，或直接在待机窗口打字回车。
